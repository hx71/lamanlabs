FAQ

Pertanyaan Umum

Bagaimana cara memesan? +

Pilih paket, lalu tekan tombol pesan. Anda akan diarahkan ke WhatsApp dengan pesan yang sudah terisi. Saya akan mengonfirmasi pesanan dan meminta data konten Anda.

Berapa lama pengerjaannya? +

Basic 2 hari kerja, Standard 3 hari kerja, dan Premium 5 hari kerja, dihitung sejak konten Anda saya terima lengkap. Waktu pengerjaan custom mengikuti estimasi yang saya kirim.

Berapa kali saya bisa minta revisi? +

Basic 1 kali, Standard 2 kali, Premium 3 kali, dan custom 3 kali. Revisi tambahan dikenakan biaya.

Bagaimana cara pembayarannya? +

Pembayaran lewat transfer bank atau e-wallet. Rinciannya kita sepakati di WhatsApp.

Apakah sudah termasuk domain dan hosting? +

Paket Standard termasuk domain .my.id dan hosting 1 tahun. Paket Premium termasuk domain .com dan hosting 1 tahun. Paket Basic tidak termasuk; file website saya serahkan ke Anda.

Apa yang perlu saya siapkan? +

Teks profil, logo, foto, daftar layanan, kontak, dan tautan media sosial. Pada paket Premium, teks saya bantu tuliskan.
